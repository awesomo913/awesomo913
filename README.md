# Hi, I'm Jacob

I'm an indie maker building AI developer tools and free, offline desktop apps. I build with AI coding assistants and ship everything in the open.

### AI developer tools

- **[Claude-Token-Saver](https://github.com/awesomo913/Claude-Token-Saver)** — Search a codebase in plain words and hand Claude just the functions you need, not whole files.
- **[claudemd-doctor](https://github.com/awesomo913/claudemd-doctor)** — See what your CLAUDE.md costs on every turn, and which rules never pull their weight. Available on [npm](https://www.npmjs.com/package/claudemd-doctor).

### Free, offline Windows apps

- **[VideoTranscriber](https://github.com/awesomo913/VideoTranscriber)** — Video and audio transcription. Nothing leaves your PC.
- **[speakeasy](https://github.com/awesomo913/speakeasy)** — Local voice dictation: talk, and it types wherever your cursor is.
- **[VoiceForge](https://github.com/awesomo913/VoiceForge)** — Clean up and restyle voice recordings: noise removal, pitch shift, effects.
- **[Optimizer](https://github.com/awesomo913/Optimizer)** — Find out why your PC is slow and safely pause what you don't need.

### Games and kid-friendly projects

- **[PiSenseDesigner](https://github.com/awesomo913/PiSenseDesigner)** — Pixel-art animation studio for the Raspberry Pi Sense HAT.
- **[BambooForest](https://github.com/awesomo913/BambooForest)** — 2D Pygame platformer where a panda reclaims the bamboo forest.
- **[KidsCodeAcademy](https://github.com/awesomo913/KidsCodeAcademy)** — Sandboxed coding tutorial for kids 7 and up.
